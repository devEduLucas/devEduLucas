## 🚀 About Me

I enjoy turning ideas into real software.

My main focus is building **modern and scalable applications**, combining robust backend development with intuitive frontend experiences.

I work mainly with **TypeScript, Node.js, Express and React**, while also developing mobile applications with **React Native**.

On the backend, I enjoy designing **REST APIs**, authentication systems, business rules and database integrations.

For data persistence, I work with **MySQL and Prisma ORM**.

I'm constantly improving my knowledge of software architecture, deployment and modern development practices.

Currently, I'm building **CifraWealth**, a personal finance platform where I can apply these concepts to a real-world project.

# 💰 Building CifraWealth

<div align="center">

### Personal Finance Platform

**From an idea to a complete Full Stack application.**

</div>

<br/>

CifraWealth is my current main project: a modern personal finance platform focused on making financial management simple, organized and intuitive.

The project is also an opportunity to put my Full Stack knowledge into practice by thinking about the application as a complete product — from the interface to the database.

### ⚙️ Core Stack

```text
Frontend        React + TypeScript
Backend         Node.js + Express
Database        MySQL
ORM             Prisma
Authentication  JWT + bcrypt
Architecture    REST API
```

### 🎯 Project Goals

- Build a maintainable Full Stack architecture
- Create a clean and intuitive user experience
- Develop a structured REST API
- Implement secure authentication
- Organize financial data efficiently
- Apply good development practices
- Deploy the application to production
- Continuously improve the architecture

<br/>

> **Status:** 🚧 Currently in development.
